## 十、日常找新岗位的操作流程

```
每周花 30 分钟：

周一早上：
  1. BOSS直聘 → 搜"BMS算法" "EMS" "能量管理" "控制算法"
     → 按最新发布排序 → 符合条件的加进清单
  2. 北极星招聘 → 储能/电池板块 → 看新岗位

周三中午：
  3. 刷一遍关注的招聘公众号（5分钟）
     → 看到新公司的校招启动 → 加进清单
  4. 国聘网 → 搜"新能源" "储能" "控制" → 看央企新岗位

周五：
  5. 牛客网 → 校招日程 → 看新公司
  6. 发现的每家公司 → 去官网确认校招/社招 → 加进 Excel

每月一次：
  7. 在猎聘/BOSS上更新简历，保持"求职中"状态
     → 让猎头主动找你
```
