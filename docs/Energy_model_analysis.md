## 二、系统组成

### 2.1 工况生成器（Driving Cycle Generator）
- **输入：** 1个（可能为时间或开关信号）
- **输出：** 1个（车速或负载功率曲线）
- **说明：** 生成标准驾驶工况（WLTC/CLTC/NEDC）用于仿真。

### 2.2 推进电机（Traction Motor）
- **输入：** 1个（来自工况生成器的功率需求）
- **输出：** 1个（机械负载或电流需求）
- **说明：** 模拟整车电机负载，将工况车速转换为功率需求。

### 2.3 240kW功率分配（核心EMS策略）
- **输入：** 5个
- **输出：** 8个
- **说明：** 当前的能量管理控制策略。将总功率需求分配到8组燃料电池上。
- **内部结构：** 包含子系统和多个Scope用于监控。
- **TODO：** 这是后续要替换为 ECMS/MPC/RL 策略的核心模块。

### 2.4 燃料电池子系统（Subsystem × 8）
每个子系统包含：
- **输入：** 3个（功率目标P_target、总线电压V_out、时钟dt）
- **输出：** 3个（DCDC输出电流Iout、DCDC输入电流Iin、输出电压Vin）
- **内部：**
  - **32kW燃料电池**：电堆模型
  - **DCDC变换器（×2）**：DC/DC转换器
  - **目标输出功率**：功率跟踪控制
  - **输出电流加载限制**：电流保护
- **说明：** 8组并联，总功率 8 × 32kW = 256kW（标称240kW）。

### 2.5 阀控式铅酸蓄电池（VRLA Battery × 2）
- **输入：** 3个
- **输出：** 2个
- **说明：** 两个铅酸蓄电池组，作为混合动力系统的储能环节，吸收和补充功率。

### 2.6 功率转换电流（Power to Current）
- **输入：** 2个
- **输出：** 1个
- **说明：** 将功率信号转换为电流信号，用于电池/FC的电流控制。

## 三、数据流

### 3.1 主功率流
```
工况生成器 → 推进电机（计算功率需求）
                ↓
         240kW功率分配（决定各FC和电池的输出）
          /         |          \
         ↓          ↓           ↓
   Subsystem1    Subsystem2   ... Subsystem8  (8×32kW FC)
    + 阀控式铅酸蓄电池 × 2
                ↓
         功率转换电流
```

### 3.2 控制信号流
```
工况生成器（车速/负载）
    ↓
240kW功率分配 ←── 电池SOC反馈 ←── 阀控式铅酸蓄电池
    ↓
各FC功率目标 → Subsystem(1-8)
```

## 四、当前策略分析

当前 `240kW功率分配` 模块实现的是**规则控制（Rule-based）**策略，可能为：
1. **功率跟随模式**：负载功率由FC直接提供，电池削峰填谷
2. **恒温器模式**：电池SOC低于阈值时启动FC，高于阈值时关闭FC

**需要你在Simulink中打开该模块确认具体实现逻辑。**
